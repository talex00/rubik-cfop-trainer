# rubik-cfop-trainer

MVP-тренажёр кубика Рубика 3x3 по методу CFOP: геометрия и полная нотация ходов, валидатор состояний, случайные скрамблы, поиск оптимального креста и решений пар F2L. Без внешних зависимостей — только Node.js.

## Возможности

- **Геометрия и ходы.** Разметка 54 фейслетов, 12 рёбер и 8 углов; повороты граней (U, D, R, L, F, B), двойные и обратные (R2, U'), повороты всего куба (x, y, z).
- **Нотация.** Разбор алгоритмов с широкими ходами (u, Rw), средними слоями (M, E, S) и вращениями куба; упрощение последовательностей (R R' -> пусто, R L R' -> L).
- **Валидатор.** Проверка типа и длины, счётчиков цветов, различия центров, целостности деталей, дубликатов, закрутки углов, флипа рёбер и чётности перестановок.
- **Скрамблы.** Случайные последовательности ходов без двух подряд ходов одной оси.
- **Оптимальный крест.** Все оптимальные решения креста: кодирование позиций четырёх рёбер, таблица дистанций (обратный BFS по 24^4 состояниям), перебор с прунингом и канонизацией.
- **Пары F2L.** Решение пары «угол нижнего слоя + ребро среднего слоя» с сохранением креста и ранее собранных пар; вращения y — законные ходы; поиск от оптимума до оптимум + 3 с верификацией на реальном состоянии.
- **Полный разбор.** Выбор лучшего варианта креста по стоимости последующего F2L и жадное послойное решение четырёх пар.

## Установка

Требуется Node.js не ниже 18. Внешних зависимостей нет.

```sh
git clone https://github.com/talex00/rubik-cfop-trainer.git
cd rubik-cfop-trainer
npm test      # прогон модульных тестов
npm run demo  # случайный скрамбл и полный разбор
```

Глобально: `npm i -g .` добавляет команду `rubik-cfop`.

## Команды CLI

```sh
rubik-cfop demo                  # случайный скрамбл (25) и полный разбор
rubik-cfop scramble             # случайный скрамбл длины 20
rubik-cfop scramble 15          # скрамбл длины 15
rubik-cfop validate "R U R' U'" # проверить состояние после ходов
rubik-cfop cross "F R U2 L'"    # оптимальные решения креста
rubik-cfop f2l --slot FR        # решение пары FR после случайного скрамбла и креста
rubik-cfop f2l --slot=BL "…54 символа URFDLB…"
rubik-cfop solve "D2 R' F2 L B' U'"
```

То же самое локально, без установки: `node src/cli.js demo` и так далее.

## Форматы входа

Команды `validate`, `cross`, `f2l` и `solve` принимают состояние в одном из двух видов:

1. **Строка ходов** — последовательность в обычной нотации, например `"R U R' F2 x y2"`. Состояние получается применением ходов к собранному кубу.
2. **Строка состояния** — 54 символа из `URFDLB` (цвет грани, разметка Коциембы: U1..U9, R1..R9, F1..F9, D1..D9, L1..L9, B1..B9). Пробелы игнорируются, регистр не важен.

Без входа команды `cross`, `f2l` и `solve` берут случайный скрамбл (для `f2l` крест собирается автоматически).

## Архитектура

- `src/geometry.js` — разметка фейслетов, слоты рёбер и углов, перестановки поворотов.
- `src/moves.js` — ключи ходов, перестановки, применение к состоянию, инверсия.
- `src/notation.js` — разбор и упрощение алгоритмов.
- `src/state.js` — собранное состояние, применение алгоритма, конвертация facelet-строк.
- `src/validator.js` — проверка физической корректности состояния.
- `src/scrambles.js` — случайные скрамблы.
- `src/solvers/tables.js` — таблицы переходов слотов и ориентаций по набору ходов.
- `src/solvers/cross.js` — кодирование креста, дистанции, поиск всех оптимальных решений.
- `src/solvers/f2l.js` — кодирование пары, орбита 24 ориентаций центров, дистанции, поиск решений пар.
- `src/analysis.js` — варианты креста с оценкой F2L, жадный разбор, сводный отчёт.
- `src/cli.js` — интерфейс командной строки.
- `test/` — модульные тесты (node:test).

## Ограничения MVP

- Последний слой (OLL и PLL) не решается: разбор останавливается после F2L.
- Крест — только оптимальные решения (это гарантированный минимум); пары F2L — от оптимальной длины до оптимум + 3.
- Пары F2L выбираются жадно, одна за другой; глобальная оптимальность порядка пар не гарантируется.
- Полный разбор случайного скрамбла занимает секунды: таблицы дистанций BFS строятся по мере необходимости и кэшируются в памяти процесса.
- Кросс-валидация решений выполняется на реальном состоянии, поэтому выдаваемые последовательности всегда корректны.
